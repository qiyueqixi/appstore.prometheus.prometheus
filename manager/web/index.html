DATA MIGRATION

迁移原版 Prometheus 数据

Control 不会自动移动或删除原版文件。必须使用随包脚本迁移，不能用 cp、rsync 或文件管理器把原版文件直接合并到现有 data/。

原版数据
Control 数据
  1. 停止两个应用在应用中心停止原版 Prometheus 和 Prometheus Control，避免复制正在写入的 WAL。
  2. 只运行迁移脚本脚本先复制到暂存目录，并把 Control 已有的初始化数据移入回滚目录，不会直接混合两套数据。
  3. 等待“迁移完成”脚本会检查磁盘空间、配置、WAL 与 head chunk 序列；出现错误时不要启动 Control。
  4. 仅启动 Control 验证确认历史查询和采集正常后，再决定是否重新启动或卸载原版应用。
禁止直接覆盖 data 目录 把原版高编号 WAL 与 Control 初始化的低编号 WAL 混在一起，会导致 segments are not sequential 并使 Prometheus 无法启动。
